  Domain:        & Cyber Security / Digital Forensics \\
  Application:   & A smart-contract system that records the SHA-256 fingerprint of each
                   digital evidence file (CCTV clips, phone images, disk images) and every
                   custody handover between police, evidence room, forensic lab and court on
                   Ethereum. Files stay off-chain. Handovers need the receiver's approval,
                   the lab's analysis is rejected if the file hash has changed, and anyone
                   can re-hash a file to prove it was not tampered with. The court seals the
                   record when the case ends, so the chain of custody cannot be edited, even
                   by the system admin. \\
